# 심바 런 (Simba Run) 🦁

라이온킹 테마의 가로모드 모바일 러너 게임. 슈퍼마리오 같은 구성으로 주인공 **심바**가 다섯 개의 대지를 왼쪽에서 오른쪽으로 달립니다.

![screenshot](screenshot.png)

## 게임 방법

- **화면 탭 = 점프** (최대 **2단 점프**)
- **물속에서 탭 = 헤엄** (탭할 때마다 위로 스트로크 — 바닥까지 가라앉으면 익사)
- 🍑 **열매**를 먹으면 추가 점수
- 거리가 늘수록 속도가 빨라지고 적이 촘촘해집니다.

데스크톱: **스페이스/↑** 점프, **P** 일시정지, **1 / 2 / 3** 배속.

## 지형

지형은 계속 변형됩니다.

- ⛰️ **오르막·내리막** 언덕
- 🕳️ **낭떠러지** — 점프로 건너뛰기 (모든 낭떠러지는 최대 2단 점프로 통과 가능하도록 폭이 제한됩니다)
- 🌊 **물웅덩이** — 헤엄쳐서 통과

## 스테이지 (5개 대지, 순환하며 난이도 상승)

| # | 스테이지 | 대표 적 |
|---|----------|---------|
| 1 | ☀️ 주간 초원 | 하이에나, 검은 갈기 사자 |
| 2 | 🌙 야간 초원 | **치타**, 사자 |
| 3 | 🕯️ 동굴 | **뱀**, 하이에나 |
| 4 | 🏔️ 킬리만자로 | 사자 (가파른 등반) |
| 5 | 🏜️ 사막 | **전갈**, 선인장 |

물웅덩이에는 어느 대지에서나 **악어**가 도사립니다. 모든 적은 최대 2단 점프로 넘을 수 있게 배치됩니다.

## 조작 UI

화면 상단 중앙에 컨트롤 바가 있습니다.

- ⏸ **일시정지 / 재생**
- **1× / 2× / 3×** 배속

## 실행

외부 의존성 없는 단일 HTML 파일입니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속 (모바일은 가로로)
```

디버그: URL 뒤에 `#debug` 를 붙이면 `window.__dbg` 로 바이옴 이동·적 소환·지형 스캔 도구가 열립니다.

## 기술

- 순수 HTML5 Canvas + Vanilla JavaScript (프레임워크·에셋 없음)
- 월드 좌표 + 카메라 스크롤 기반 절차적 지형 생성 (클리어 가능성 보장 규칙 포함)
- 캐릭터·배경·적 전부 Canvas 벡터 드로잉
- 가로모드 최적화, 세로 시 회전 안내, `devicePixelRatio` 대응
- 최고 점수는 `localStorage` 저장
